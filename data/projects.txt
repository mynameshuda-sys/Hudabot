PROJECT 1: CCTV CLOTHING RECOGNITION SYSTEM

Objective:
The project focuses on analyzing Pakistani CCTV footage and identifying what people are wearing.

Main Idea:
The system processes CCTV footage, detects people, extracts person regions, and analyzes clothing attributes.

Potential Technologies:
- Python
- Computer Vision
- Deep Learning
- Object Detection
- Image Classification
- Multimodal AI

Dataset Work:
The project involved processing CCTV images and person crops, checking image quality, detecting duplicates, and preparing annotated data for machine learning.

The desired person crop contains as much of the person as possible, including the head, face where visible, shoulders, arms, hands, legs, and feet. Images where the face is not visible can be separated for later processing.

Current Modeling Direction:
The initial goal is to build a system that can describe what a person is wearing. A more advanced multimodal approach can be considered after sufficient annotated data is available.

PROJECT 5: PERSONAL RAG CHATBOT - HUDABOT

Objective:
HudaBot is a Retrieval-Augmented Generation chatbot designed to answer questions using a custom personal knowledge base.

Core technologies:
- Document preprocessing
- Text chunking
- Sentence Transformer embeddings
- FAISS vector search
- Large Language Model
- Prompt engineering
- Conversation history
- Streamlit interface

The chatbot should answer questions using retrieved information from the custom dataset and should avoid inventing information that is not present in the knowledge base.
