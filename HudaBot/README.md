# HudaBot - Groq Version

RAG chatbot using a custom TXT knowledge base, SentenceTransformer embeddings, FAISS, Groq, and Streamlit.

Local:
1. `pip install -r requirements.txt`
2. PowerShell: `$env:GROQ_API_KEY="YOUR_GROQ_API_KEY"`
3. `streamlit run app.py`

Streamlit Cloud secret:
`GROQ_API_KEY = "YOUR_GROQ_API_KEY"`

Never commit your API key.
